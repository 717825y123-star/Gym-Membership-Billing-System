Gym Membership and Billing System

 Problem Statement

Gyms need a simple way to manage members, membership plans, subscriptions, attendance, invoices, and payments. Managing these activities manually can lead to errors and difficulty tracking subscription validity and payment status.

This project is a Java-based console application that helps gym staff manage member details, assign plans, record attendance, generate invoices, process payments, and track subscription expiry and renewal.

Technologies Used

- Java
- Eclipse IDE
- Object-Oriented Programming
- Java Collections

Features

- Add and display gym members
- Add and display membership plans
- Start and renew subscriptions
- Record attendance
- Generate invoices with tax and renewal penalties
- Record payments and payment status
- View attendance summaries
- Simulate subscription expiry

How to Compile and Run

1. Download or clone this repository.
2. Open Eclipse IDE.
3. Select File → Import → Existing Projects into Workspace**.
4. Choose the downloaded project folder and click **Finish**.
5. Open `src/main/Main.java`.
6. Right-click the file and select **Run As → Java Application**.
7. Use the menu displayed in the Eclipse Console to interact with the application.
